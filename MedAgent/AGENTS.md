# MedAgent 工作边界

- 仅在本目录新增或修改 DSH 适配、测试、脚本和文档。
- Python 掌握医学状态机、业务校验、预算和最终提交；DSH 只提供可替换的角色执行能力。
- `../MedSearch/` 是外部只读依赖：不得移动、复制、改写其模型、数据、索引、SFT 或 RL 实现。
- 当前 smoke 不注册模型可调用工具，不允许 shell、文件写入、网页访问或临床系统访问。
- 每次只实现一个可验证能力，并保存命令、版本、输入和输出摘要；不得编造实验结果。
- 医学输出必须标注研究用途，不能作为临床诊断或治疗建议。
- 待实现规格以 `ENGINEERING_PLAN_V1_V2.md` 为准；一次只指导一个有实际输入输出的能力，不按旧函数数量补空模块。
- 默认不新增自动重试、动作修复、兼容协议、备用模型或存储回退；技术失败在所属边界暴露，不能吞掉后伪装成空结果或医学弃答。
- 已实现部分不因规划更新而重构；真正接线遇到接口差异时只改必要位置，不建第二套兼容框架。
